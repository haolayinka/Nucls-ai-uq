# Reproducibility contract

- Exact SHA-256 verification is appropriate for deterministic canonical CSV/JSON/NPZ artifacts, source manifests, frozen data packages, and checkpoints where feasible.
- Stochastic Bayesian posterior artifacts are validated by numerical/scientific equivalence unless the frozen runtime proves byte identity.
- Rendered PDF byte identity is not a publication requirement because renderer metadata can alter bytes.
- Official NuCLS raw data should not be redistributed unless its license explicitly permits redistribution; provide acquisition/staging instructions and source hashes instead.
- `DidNotAnnotateFOV` remains missing/unobserved; `undetected` remains an observed negative.
- NuCLS P-truth is an inferred multirater reference, not independently verified biological truth.
